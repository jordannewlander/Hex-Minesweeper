# Hex-Minesweeper
Minesweeper where GUI buttons are flat-topped hexagons
//READ ME
/**
* How to play game:
* run main method in HexMineGUI class
* click on which size game you want to play
* - small: rows = 4, cols = 4, mineNum = 3
* - large: rows = 6, cols = 6, mineNum = 4
* right click to uncover cell/ test if it has a mine,
* left click to flag/unflag mine
* PLEASE TRY TO CLICK IN CENTER OF HEX BUTTONS BECAUSE POLYGON BOUNDS ARE FINICKY 
* note: if you press the small or large board buttons while you are playing, it will restart your game
* no real scoring method, just play until you win/lose
